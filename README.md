# 爱宠智诊 —— AI 宠物医药智能服务平台 🐾

> 基于 **Spring Boot 3 + Vue 3 + MyBatis-Plus + 通义千问大模型 (DashScope)** 构建的一站式 AI 宠物健康预诊、执业兽医远程问诊、电子处方全流程合规核验与处方药电商服务系统。

---

## 📖 项目简介

**爱宠智诊**平台旨在解决传统宠物就医信息不透明、轻症就医成本高、处方药流转不合规等痛点。系统结合大语言模型强大的自然语言理解与推理能力，为养宠家庭提供 7×24 小时智能预诊服务，并打通 **「AI 智能初诊 ➡️ 执业兽医接诊 ➡️ 合规电子处方开具 ➡️ 药、方、宠三方核验 ➡️ 药品合规商城与物流追踪」** 的全流程闭环。

---

## 🌟 核心功能模块

### 1. 🤖 AI 宠物智能健康问诊（SSE 流式响应）
- **多轮交互预问诊**：基于宠物档案（品种、年龄、性别等）与当前病情描述，开展智能对话。
- **结构化评估输出**：实时评估病情紧急程度（低/中/高）、提供病因分析、家庭护理对策及就医指引。
- **OTC 药品智能推荐**：推荐对症非处方药，并在对话中自动生成直达商城详情页的购买链接。
- **医疗安全边界**：内置固定免责声明与重症急诊送医强制警示。

### 2. 👨‍⚕️ 在线兽医服务与电子处方流转
- **在线问诊会话**：用户可一键发起线上执业兽医人工问诊，兽医端实时接诊。
- **病历调阅与诊断**：兽医可调阅宠物终身医疗健康档案，出具专业诊断结论。
- **电子处方签发**：规范开具包含有效期限、用法用量、处方药品清单的合法电子处方。

### 3. 💊 药品合规商城与交易闭环
- **处方药严格管控**：将药品明确划分为 OTC（非处方药）与 Rx（处方药）。
- **药 / 方 / 宠三方自动化核验**：购买处方药时强制拦截，严格校验处方时效性、宠物归属与处方内用药明细。
- **商城完整生命周期**：药品智能检索、购物车、模拟支付结算、自动扣减库存、商家发货与全流程物流轨迹追踪。

### 4. 📋 宠物全生命周期健康档案
- **终身电子档案**：记录宠物基础资料、过敏史、慢性疾病史、疫苗接种与用药记录。
- **档案与就诊联动**：在智能问诊与医生开方时无缝共享健康数据。

### 5. 📊 运营管理控制台
- **执业资质审核**：兽医师入驻资质审核与封禁联动。
- **药品 SKU & 库存维护**：药品上架/下架、修改、实时库存告警。
- **处方流转监管**：全平台电子处方监控与核销记录追溯。
- **运营大盘看板**：实时在线人数、近 7 日订单趋势折线图、处方总量与核心指标可视化。

## 🛠️ 技术栈

### 后端架构
- **核心框架**：Spring Boot 3.4.3
- **ORM & 数据持久**：MyBatis-Plus 3.5.9
- **数据库**：MySQL 8.0
- **AI 大模型服务**：阿里云 DashScope SDK（通义千问 Qwen-Plus 模型）
- **通信机制**：SSE (Server-Sent Events) 单向流式推流
- **安全与权限**：Spring Security + 自定义 Token 鉴权
- **代码增强**：Lombok、SLF4J

### 前端架构
- **核心框架**：Vue 3 + TypeScript + Vite
- **UI 组件库**：Element Plus + Element Plus Icons
- **路由 & 状态**：Vue Router + Pinia / Reactive Store
- **样式**：现代响应式 CSS3 + 玻璃拟态设计风格

## 🚀 快速启动指南

### 1. 数据库准备
1. 安装并启动 MySQL 8.0 服务。
2. 创建数据库（例如 `pet_clinic`），导入 `server/src/main/resources/sql/schema.sql` 中的表结构及初始数据。

### 2. 后端服务启动
1. 进入 `server` 目录。
2. 检查 `src/main/resources/application.properties` 中的数据库账号密码及 `ai.api-key`。
3. 执行 Maven 命令运行项目：
   ```bash
   mvn spring-boot:run
   ```
   后端服务默认运行在 `http://localhost:8080`。

### 3. 前端工程启动
1. 进入 `web` 目录。
2. 安装依赖并启动本地开发服务器：
   ```bash
   npm install
   npm run dev
   ```
   浏览器访问 `http://localhost:5173` 即可体验平台全部功能。
